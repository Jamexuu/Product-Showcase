# Product-Showcase
System Integration and Architecture - AI integration Activity

## Setup Guide

### Requirements
- PHP 8.1 or higher
- Composer
- XAMPP
- Ollama

### Installation Steps

1. **Install Ollama**  
   Download from [https://ollama.ai](https://ollama.ai) and install

2. **Run the AI Model**
   ```bash
   ollama run qwen3:0.6b
   ```
   This will download the model and start the Ollama server. You can exit the chat after it starts.

3. **Install PHP Dependencies**
   ```bash
   composer install
   ```

4. **Create `.env` File**  
   Create a file named `.env` in the root folder:
   ```env
   This is privately provided
   ```

5. **Run the Application**
   - Start XAMPP Apache server
   - Open browser: `http://localhost/Product-Showcase/index.php`
